# Power-Log

Android-basert mobilapplikasjon for loggføring av styrketrening, utviklet i PROG2052 - Integrasjonsprosjekt.

## Om prosjektet

Power-Log er en intuitivt, enkel og gratis treningsapplikasjon. Applikasjonen følger et lokal-først-prinsipp hvor all funksjonalitet er tilgjengelig uten nettilgang, med synkronisering og sikkerhetskopiering via backend.

**Kjernefunksjonalitet:**
- Opprett og bruk egne treningsmaler
- Loggfør øvelser og sett under trening
- Detaljert treningshistorikk

## Teknisk stack

- **Frontend**: Kotlin, Jetpack Compose, Room, Hilt
- **Backend**: Go, MongoDB
